## 背景

抽屉里两部退役安卓机（一部 6 寸、一部 5.5 寸），电池还能撑。想拿来当桌面副屏：

- 常亮显示日历 + 待办 + 天气
- 插着电 7×24 运行
- 手机本身就是一个完整的浏览器，理论上做个网页就完事

## 方案

思路很直接：手机装一个「全屏浏览器 + 常亮」的壳，加载局域网里的一页仪表盘。

1. 仪表盘用纯 HTML/CSS 写，定时刷新
2. 手机端用 WebView 全屏，加 `FLAG_KEEP_SCREEN_ON`
3. 数据由一个本地脚本定时抓取，写到静态 JSON

代码量很小，问题全在硬件。

## 过程

软件部分一天就写完了，效果其实还不错：

```kotlin
window.addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
webView.settings.javaScriptEnabled = true
webView.loadUrl("http://192.168.1.10:8080/dash/index.html")
```

配合定时刷新的 JS，屏幕内容每天自动变化。

## 踩坑

真正劝退的是这几条：

| 现象 | 原因 | 后续 |
| --- | --- | --- |
| 屏幕常亮后，三天就出现淡影 | OLED 长时间显示固定 UI 导致烧屏 | 想加像素微移，但白底内容没法彻底避免 |
| 充电时电池鼓包风险 | 长期 100% 电量高温充电 | 需要拆机改「直供」供电，风险高 |
| 屏保/自启被系统杀掉 | 厂商 ROM 的省电策略 | 关不干净，重启后得手动点一次 |
| 表面温度 45℃+ | 常亮 + 充电 + 无风 | 没有散热设计的手机机身 |

最后一条是压倒性的：**这不是软件能解决的问题**。

## 结果

**放弃。** 三天，9 小时，0 元（没买任何配件）。

替代方案：桌上本来有一块吃灰的平板，它常亮不烧屏、电池大、能直接插电源。
用同一个网页仪表盘，5 分钟搞定，现在还在跑。

## 复盘

- 软件部分的代码复用到了平板上，不算全白干
- 教训：**动手前先问"硬件层面的约束我能不能改"**，改不了就别投入时间写壳
- 这类「旧设备再利用」的项目，成功率高度取决于设备本身的物理特性，而不是代码

在项目状态里我给它标了 `翻车`。失败也是记录——下次再有人想干同样的事，至少知道卡在哪。
